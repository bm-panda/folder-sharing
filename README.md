# 局域网共享

> 一键将文件夹共享到局域网（SMB），支持只读/读写权限选择、取消共享、查看当前共享列表，自动生成 `\\电脑名\共享名` 访问地址。

---

## 核心特性

- **一键共享**：选中文件夹右键即可共享到局域网，也可在启动窗口中浏览选择
- **权限可选**：只读 / 读写两种权限，默认只读更安全
- **免密/密码访问可选**：默认自动启用来宾(Guest)账户实现局域网免密访问；关闭开关则需输入本机账号密码访问（更安全）
- **自动补齐文件夹安全权限**：共享时自动为文件夹添加 Everyone 的 NTFS 权限，避免"共享了但打不开"
- **可取消共享**：选中已共享的文件夹，一键取消共享
- **查看共享列表**：随时了解当前机器对外开放了哪些共享
- **自动打通访问环境**：共享时自动把网络设为专用、启用网络发现与"文件和打印机共享"防火墙规则、启动 FDResPub/fdPHost 发现服务，让局域网其他设备能发现和访问
- **盒子图形界面**：自动生成启动窗口，填完点执行即可
- **支持脚本联动**：声明为节点脚本，其他脚本可调用它并拿回 UNC 访问路径

## 安装方法

本脚本的运行环境及图形化窗口均依赖"不忙脚本盒子"，建议仅通过盒子安装和使用本脚本。

> 前置条件：安装好 [不忙脚本盒子](https://www.bm-box.cn)

* 打开盒子 → **脚本市场** → 搜索 **「局域网共享」**
* 点击「安装」

---

## 使用方式

* 直接启动
  * 在盒子里点击脚本卡片，弹出启动窗口
  * 选择要共享的文件夹，选择操作（共享/取消共享/查看列表）与权限，点「执行」
* 右键启动
  * 在文件管理器中选中文件夹，右键 → 选择「局域网共享」
  * 默认按「共享 + 只读」执行（可在启动窗口修改默认值）
* 自定义共享名
  * 启动窗口中填写「共享名」，留空则使用文件夹名

## 💡 使用提示

* 共享/取消共享需要管理员权限，首次执行会弹出 UAC 提权窗口，请允许
* 执行「共享」时脚本会自动开启网络发现环境（网络改为专用、放行防火墙、启动发现服务），无需手动配置；这会把当前网络标记为"专用"，若在公共 Wi-Fi 下使用请注意隐私，可在"设置 → WLAN"改回公用
* 「免密访问」开启时脚本会启用系统内置 Guest 账户（他机双击即开、不用密码）；关闭时他机首次访问需输入本机的 Windows 账号密码，更安全。不管哪种，文件夹的 NTFS 权限都会自动补 Everyone
* 若访问方电脑（Win10/11）提示"组策略阻止不安全的来宾登录"，需在**对方电脑**管理员运行：`reg add HKLM\SOFTWARE\Policies\Microsoft\Windows\LanmanWorkstation /v AllowInsecureGuestAuth /t REG_DWORD /d 1 /f`
* 权限设为 Everyone，建议仅在可信局域网（家庭/办公内网）环境使用
* 其他设备访问地址为 `\\你的电脑名\共享名`；也可在"网络"邻居列表中看到本机（首次发现可能延迟数秒）
* 同名共享重新创建时会覆盖旧设置，可用此方式切换只读/读写权限

## 节点脚本(开发者阅读)

本脚本已声明为节点，被联动调用（`invoke_mode == "node"`）时回传信封：

```python
import json, sys, requests

payload = json.load(open(sys.argv[1], encoding='utf-8'))
env = payload["environment"]

r = requests.post(f"{env['api_base']}/api/link", json={
    "script_id": "220949a5-1a53-4688-95b1-b70a13eebf8e",
    "data": {"folder_paths": ["D:/share-demo"]},
    "params": {"action": "share", "permission": "read"},
}, timeout=300)
body = r.json()
if body.get("success"):
    print(body["result"]["share_paths"])   # ["\\电脑名\\share-demo"]
    print(body["result"]["summary"])
```

业务键说明：

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `share_paths` | 字符串数组 | UNC 访问路径列表 |
| `summary` | 字符串 | 每个文件夹的处理结果概要 |
